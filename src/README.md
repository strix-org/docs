# Strix Lua API

Скрипты Strix пишутся на [Luau](https://luau.org) и работают внутри клиента: объявляют модули с настройками, подписываются на события, встраивают код в методы Minecraft, рисуют в мире и на экране, вызывают любой код игры.

```lua
local m = strix.module("Hello", { category = "Misc" })
local times = m:slider("times", { min = 1, max = 10, step = 1, default = 3, integer = true })

m:on("enable", function()
    for i = 1, times:get() do
        print("Привет,", i)
    end
    strix.toast("Hello включён", { tone = "success" })
end)
```

Вставь это во вкладке **Скрипты** → **Новый** → ✎, нажми **Сохранить**, включи переключатель скрипта. В категории **Misc** появится модуль **Hello**: включается, биндится и сохраняется в конфиг как встроенный, а настройка `times` появляется в его панели.

## Важно знать сразу

- **Скрипт исполняется только на основном потоке игры.** Сетевые потоки до него не доходят.
- **Один вход в скрипт не дольше 100 мс.** Дольше — скрипт прерывается, модуль выключается, игра идёт дальше.
- **Сбой изолирован.** Ошибка в обработчике пишется в консоль и выключает только этот модуль.
- **Вход в скрипт стоит времени:** порядка 150 мкс на вызов с несколькими обращениями к игре. На горячие точки (кадр на сущность, рендер блока) ставь `inline` или проверяй условие редко.
- **Имена Minecraft настоящие:** `player:getYRot()`, как в исходниках игры. При обновлении Minecraft имя может измениться, и скрипт упадёт с ошибкой при запуске этого кода.
