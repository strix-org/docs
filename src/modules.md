# Модули и настройки

## `strix.module`

```lua
local m = strix.module("AutoGG", { category = "Misc" })
```

`strix.module(name, spec)` → `StrixModule` объявляет модуль: имя из букв, цифр и `_`, категория — `Combat`, `Movement`, `Misc`, `Render` или `Client` (по умолчанию `Misc`). Любое другое имя из букв, цифр, `_` и пробелов — своя вкладка в меню: так большой скрипт собирает свои модули вместе (`{ category = "DiamondWorldUtilities" }`). `description` — подпись карточки в меню: строка или `{ en = "…", ru = "…" }`. Ключ модуля в конфиге — `script:AutoGG`. Модуль появляется в меню, биндится и сохраняется как встроенный.

Обработчики вешаются через `m:on(событие, функция)`, см. [События](events.md), а хуки через `m:hook`, см. [Хуки](hooks.md). Они работают, пока модуль включён.

## Настройки

Каждый метод возвращает настройку: `s:get()` читает значение, `s:set(v)` меняет его. Запись применяется при выходе из обработчика, а неверное значение пишется в консоль и не меняет настройку.

| Метод | Значение | Описание |
|---|---|---|
| `m:toggle(key, { default })` | boolean | Переключатель |
| `m:slider(key, { min, max, step, default, integer })` | число | Ползунок; `integer` — целый |
| `m:range(key, { min, max, step, from, to, integer })` | `{ from, to }` | Отрезок |
| `m:mode(key, { options, default })` | строка | Один из вариантов |
| `m:multi(key, { options, default })` | `{ [вариант] = true }` | Несколько вариантов; `default` — список |
| `m:text(key, { default })` | строка | Текст |
| `m:color(key, { default, alpha })` | `{ r, g, b, a }` | Цвет; `alpha` — с прозрачностью |
| `m:bind(key, { default, mouse })` | `{ key, mouse }` | Клавиша GLFW или кнопка мыши |
| `m:items(key, { default, colors })` | список id | Предметы; `colors` — свой цвет у пункта |

Общие поля описания:

- `group = "имя"` кладёт настройку в секцию панели;
- `visible = function() return ... end` прячет настройку по условию. Функция зовётся каждый кадр панели, поэтому держи её дешёвой.

```lua
local mode = m:mode("mode", { options = { "fast", "legit" }, default = "legit" })
local speed = m:slider("speed", { min = 0, max = 10, default = 5,
    visible = function() return mode:get() == "fast" end })
```

Ключ настройки одновременно и ID в конфиге, и подпись в меню. Человеческие подписи задаёт `strix.i18n.set`:

```lua
strix.i18n.set("speed", { en = "Speed", ru = "Скорость" })
```

## Чужие модули

`strix.modules.list()` возвращает ключи всех модулей, встроенных и из скриптов. `strix.modules.get(key)` → `StrixModuleRef?` даёт доступ к модулю или `nil`:

```lua
local aura = strix.modules.get("Aura")
if aura and aura:is_enabled() then
    print(aura:settings())
    print(aura:get("settings.aura.range"))
    aura:set("settings.aura.range", 3.5)
    aura:set_enabled(false)
end
```

Методы: `key()`, `is_enabled()`, `set_enabled(on)`, `get(setting)`, `set(setting, value)`, `settings()`, а также экспорт — `state()`, `actions()`, `call(name, ...)` (ниже). Модуль, который сейчас исполняется выше по стеку, недоступен: `get` вернёт `nil`, вызовы дадут ошибку.

Чтобы следить за изменениями чужих модулей, подпишись на событие `module_changed`.

## Экспорт модуля

Кроме настроек модуль может показать скриптам **состояние** и **действия** — только то, что сам объявил. Остальное
устройство модуля скрипту не видно.

```lua
local totem = strix.modules.get("AutoTotem")
if totem and totem:is_enabled() and totem:state().busy then
    return -- тотем кладётся в руку: не мешаем
end
```

| Метод | Что делает |
|---|---|
| `ref:state()` | Таблица объявленного состояния на этот момент. Это копия: запись в неё модуль не меняет |
| `ref:actions()` | Имена объявленных действий |
| `ref:call(name, ...)` | Вызвать действие; аргументы и результат — данные или объекты игры. Ошибка действия — ошибка твоего скрипта (ловится `pcall`), модуль работает дальше |

Свой модуль объявляет экспорт при загрузке скрипта:

```lua
local m = strix.module("Zone")
local zone = nil
m:expose("zone", function() return zone end)
m:action("set_zone", function(x, z) zone = { x, z } return true end)
```

`m:expose(name, getter)` — поле состояния: `getter` зовётся на каждый `state()`, держи его дешёвым. `m:action(name, fn)` —
действие. Имена — `snake_case`. Значения — `nil`, boolean, число, строка, таблицы из них и объекты игры; функции и
объекты Strix не передаются.

Всё это — только на основном потоке. Модуль, чей обработчик сейчас исполняется, недоступен: вызов из его же обработчика
даст ошибку.

### Встроенные модули

| Модуль | Состояние | Действия |
|---|---|---|
| `AutoTotem` | `busy` — тотем кладётся в руку, движение заморожено; `main_hand_busy` — в основной руке тотем (режим «две руки»), оружие в неё сейчас не брать | — |
| `Hide` | `hidden` — id скрытых сейчас игроков | — |

## Библиотеки

Общий код нескольких скриптов выносится в библиотеку и подключается по имени:

```lua
local protocol = require("dw/protocol")
m:on("tick", function() print(protocol.state.location) end)
```

Библиотека исполняется один раз, все скрипты получают одну и ту же таблицу, так что состояние в ней общее. Внутри библиотеки можно ставить хуки (`strix.hook`), но нельзя объявлять модули. Библиотеки берутся из каталога публичных скриптов (вкладка «Скрипты» → «Публичные»); если такой нет, `require` даёт ошибку.

## Публикация

Скрипт попадает в каталог «Публичные» после модерации: команда читает каждую версию целиком и подписывает одобренную. Версия неизменяема, следующая получает новый номер. Скрипт объявляет `api_version` — под какую версию API написан; клиент со старым API его не запустит.
