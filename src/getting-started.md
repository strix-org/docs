# Начало работы

## Вкладка «Скрипты»

В меню клиента (RShift) слева пункт **Скрипты**. В строке скрипта:

- **переключатель** включает и выключает скрипт;
- **⟲** запускает заново с текущим текстом;
- **✎** открывает редактор;
- **✕** удаляет, с подтверждением в строке.

Новый скрипт создаётся выключенным. Сохранённый скрипт хранится в облаке аккаунта и в локальной рабочей копии, поэтому переживает перезапуск игры.

## Редактор

Подсветка, номера строк, подчёркивание ошибок и подсказки по API `strix.*` (набор идентификатора, `.`, `:` или Ctrl+Space). Объекты игры имеют тип `any`: подсказок по их методам пока нет.

| Клавиша | Действие |
|---|---|
| Ctrl+S | Проверить и сохранить; работающий скрипт перезапускается |
| Ctrl+Space | Подсказки |
| Tab, Enter | Подставить подсказку |
| Esc | Закрыть подсказки, затем снять фокус |

Если текст не компилируется, работает прошлая версия, а курсор встаёт на строку с ошибкой.

## Консоль

Кнопка **Консоль** в шапке открывает окно журнала: его можно перетаскивать, закрывается кнопкой или крестиком. Формат записи — `[Скрипт:строка]: сообщение ×повторы`.

- Клик по тегу с номером строки открывает скрипт на ней.
- Выделение мышью и Ctrl+C копируют текст, ПКМ копирует выделенное или строку целиком с traceback.
- Пока есть выделение, журнал не двигается.
- Поле внизу сразу выполняет код: `1 + 2`, `x = 5`, `print(strix.modules.list())`. Переменные живут между вводами.

Пишут в журнал `print`, `strix.log.info`, `strix.log.warn` и `strix.log.error`. Значения разделяются табуляцией.

## Жизненный цикл

Запуск исполняет скрипт сверху вниз. **Только в это время** можно объявлять модули, настройки, хуки, окна и элементы HUD. Потом работают только их обработчики.

Перезапуск снимает всё, что скрипт объявил, и выполняет его заново. Настройки и включённость модулей переживают это, а обычные переменные скрипта начинаются заново. Если значение должно пережить перезапуск, храни его в настройке.

У каждого скрипта своё окружение: его глобалы не видны другим. Библиотеки только для чтения.

Обновление клиента (hot reload) ведёт себя так же: скрипты запускаются заново с прежними настройками, текст в редакторе сохраняется. Несохранённая правка открывается как черновик, а работает последняя запущенная версия.

## Ограничения

| Что | Лимит |
|---|---|
| Один вход в скрипт | 2000 мс, потом прерывание |
| Память всех скриптов | 256 МБ |
| Модулей скриптов одновременно | 32 |
| Скриптов на аккаунт | 100 |
| Размер скрипта в облаке | 256 КБ в base64 (около 190 КБ текста) |

Luau без `io` и `os.exit`; `require("имя")` подключает [библиотеку](modules.md#библиотеки) по имени, а не файл. Доступ к файлам и процессам возможен только через [мост к игре](java.md), поэтому чужой код в свой скрипт вставляй, только если доверяешь ему: он получает те же права, что и клиент. Скрипты вкладки «Публичные» прошли модерацию команды.

## Значения и цвета

Цвет — число `0xAARRGGBB`, таблица `{ r, g, b, a }` со значениями 0..255 или результат `strix.color(r, g, b, a)`. Без альфы цвет непрозрачный.

Иконки — имена [Lucide](https://lucide.dev): `clock-3`, `play`, `shield`.
